# Sistema de Cadastro de Alunos
Sistema web desenvolvido para realizar o cadastro e visualização de alunos.

## Objetivo
O projeto foi desenvolvido como atividade prática da disciplina Material Design Framework.
O objetivo é aplicar conceitos de:
* Git;
* GitHub;
* HTML5;
* CSS3;
* JavaScript;
* Clean Code;
* Trabalho colaborativo.

## Tecnologias
* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## Como executar
1. Faça o clone do projeto.
`git clone URL_DO_REPOSITORIO`
2. Entre na pasta.
`cd sistema-cadastro-alunos`
3. Abra o arquivo `index.html` em um navegador.

## Funcionalidades
* Cadastro de alunos;
* Exibição dos alunos cadastrados;
* Validação básica dos campos;
* Interface responsiva.
